# Prompts
## 1. AI Audit Summary

**File:** `backend/src/services/gemini.service.ts` → `buildPrompt()`  
**Model:** `gemini-1.5-flash`  
**Temperature:** `0.2`  
**Max output tokens:** `300`  
**Timeout:** `8s` (free-tier Gemini can be slow; audit response must not block on it)  
**Fallback:** if Gemini is unavailable, rate-limited, or the key is missing, `buildFallbackSummary()` returns the same per-tool sentences stitched together deterministically — no AI needed

### What it does

Takes the audit engine output and asks Gemini to turn it into one readable paragraph. The paragraph goes into `AuditResult.aiSummary` and is shown at the top of the results page.

### What feeds it

Before the prompt is built, each tool in the audit result is converted to a single cited sentence:

**API tools** — the sentence is already generated by `auditApiTool()` in `audit.service.ts`. It contains benchmark name, benchmark URL, score, savings amount, savings percent, pricing URL, and token estimate. All numbers come directly from the audit engine.

**Subscription tools** — built by `subscriptionSentence()` in `gemini.service.ts`. Format:

- If optimal: `"Your {tool} {plan} costs ${cost}/month and is already the most cost-effective option for your use case."`
- If savings exist: `"Your {tool} {plan} costs ${cost}/month. {RecTool} {RecPlan} delivers the same capability at a lower price — switching saves ${savings}/month ({pct}% reduction)."`

These sentences are numbered and passed verbatim into the prompt. Gemini's only job is prose — all facts are pre-supplied.

### Prompt (full text)

```
You are a financial analyst writing a one-paragraph AI tool spend summary.

Below are the exact per-tool findings. Every number, model name, benchmark name, percentage, and markdown link below is verified — preserve them exactly as written.

Per-tool findings:
1. {sentence for tool 1}
2. {sentence for tool 2}
...

Total potential savings: ${total}/month   [or "none — stack is already optimal"]

Rules:
- Use every fact and every markdown link above verbatim — do not reword numbers or URLs.
- Do not invent any claim not present above.
- Do not mention "Credex".
- Output one paragraph only. No bullet points. No headers.
- Target exactly ~100 words.
```

### Design decisions

**Temperature 0.2** — the output must be factual and consistent. Higher temperature risks paraphrasing numbers or drifting from the cited data.

**`maxOutputTokens: 300`** — the target is ~100 words (~130 tokens). 300 gives headroom without allowing runaway output.

**No invented claims rule** — the audit engine already computed everything. The prompt's job is only to make it readable. Letting the model add context, caveats, or comparisons it invented would undermine trust in the output.

**Fallback is always ready** — `buildFallbackSummary()` runs before the Gemini call. If anything fails (no key, timeout, 429, bad JSON), the user still gets a complete, cited summary. Gemini is an enhancement, not a dependency.

**"Do not mention Credex"** — the summary may be shared or screenshotted by users. Credex references belong in the email flow, not in the audit output itself.
